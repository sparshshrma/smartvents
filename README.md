# s_vent
Capstone project for S-Vent application. In this project SmartVents is an end-to-end IoT system that connects Bluetooth-enabled smart air vents to a cloud-based platform for real-time environmental monitoring. The system collects hourly temperature data from vents, transmits it via Bluetooth to a connected device, and uploads it to a backend server built with Node.js and Express. Data is parsed, stored in MongoDB, and visualized on a secure, role-based web dashboard developed using React and Next.js. The frontend uses Chart.js for interactive time-series graphs, while the backend enforces user authentication and structured API endpoints. The project was developed collaboratively by a 5-member team, with responsibilities spanning full-stack development, hardware integration, and UX design.
# To run frontend
Change directory to client
run 'npm install'
then run 'npm run build' then run 'npm run start'
# To run backend
Change directory to server
run 'node install'
run 'node server.mjs'
